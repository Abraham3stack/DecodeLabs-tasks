# HealthSync 🏥

A modern, responsive healthcare landing page built with **HTML, CSS, and JavaScript** as part of the DecodeLabs Full Stack Internship.

---

## 🚀 Overview

HealthSync is a smart healthcare interface designed to provide users with a seamless way to manage appointments, access medical records, and track health data. This project focuses on **responsive design, clean UI, and real-world frontend practices**.

---

## ✨ Features

- 📱 Fully responsive (Mobile-first design)
- 🍔 Interactive hamburger menu
- 📌 Sticky navigation bar
- 🎯 Active link highlighting
- 🎨 Modern UI with clean design system
- ⚡ Smooth scrolling navigation
- 🧩 Scroll-based fade-in animations
- 📩 Functional contact form (JavaScript)
- ♿ Accessible and semantic HTML structure
- 🚀 Optimized performance (LCP, CLS improvements)

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure  
- **CSS3** – Flexbox, responsive design, animations  
- **JavaScript (Vanilla)** – Interactivity and DOM manipulation
